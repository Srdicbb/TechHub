When every outer value starts an inner stream (e.g. an HTTP call), the operator decides what to do with the overlap: **switchMap** cancels the previous one, **mergeMap** runs all of them in parallel, **concatMap** queues them one after another, and **exhaustMap** ignores new ones while the current one runs.
@a8f067e785
**switchMap**: search as you type. Only the last query matters, and old HTTP calls are cancelled.
@6f680d892e
**mergeMap**: independent jobs in parallel (e.g. uploading several files); the order of results is not guaranteed.
@66663c0eaf
**concatMap**: the order matters (saving changes one by one), so the next one waits for the previous to finish.
@774db18f8b
**exhaustMap**: a login or "Save" button. Double clicks while the request is running are ignored.
@2adfac0542
