**Bubble sort** compares neighbors and swaps them when they are in the wrong order. After every pass the largest remaining element "bubbles up" to the end. O(n²).
@5d8f620830
**Insertion sort** takes the next element (purple) and moves it left until it stops in its place in the already sorted part. O(n²), and O(n) on a nearly sorted array.
@00f9b58962
**Merge sort** splits the array into halves until single elements remain, then merges the sorted parts. The lighter part is the range currently being merged. Always O(n log n), with O(n) extra memory.
@143b4c1170
**Quick sort** picks a pivot (purple, here the last element), moves the smaller elements to the left, and the pivot lands in its final place. Then it does the same for the left and right part. O(n log n) on average.
@e05121741b
 On a reversed array the pivot is always the smallest, so the split is not in half: this is the worst case, O(n²).
@ac711a39b6
 On a nearly sorted array the last element is a bad pivot: the split is uneven and the number of comparisons grows toward O(n²).
@03521df181
 The array is nearly sorted, so no element travels far: close to O(n).
@65a7b6e3d6
 A reversed array is the worst case: every element travels all the way to the start.
@fa2e1d66aa
