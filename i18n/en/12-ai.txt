Embeddings and semantic search
@a746fbe4fb
An embedding model turns text into a vector of several hundred or thousand numbers, so that texts with similar meaning end up close together. Searching by meaning is then a search for the nearest vectors.
@bf3a5e14f6
Similarity is measured by the cosine of the angle between vectors: 1 means the same direction (the same meaning), 0 unrelated.
@ff292b8999
The same model must be used for both the documents and the query: vectors from different models are not comparable.
@b2567b74ea
Exact search compares the query with all vectors (O(n)); indexes such as HNSW find the approximately nearest ones in a fraction of the time.
@1e7b98f14b
An embedding captures meaning, not exact words: "puppy" finds "dog", but an item code is better found by classic search. Hybrid search combines both.
@f4dad044e4
